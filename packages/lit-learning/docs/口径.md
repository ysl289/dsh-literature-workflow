# 资料准备度与证据口径（0.2）

## 分数的边界

A–D 衡量本库当前抽取、字段和可回溯资料的准备程度，不衡量论文客观质量，不授予引用许可。低分可能来自本库缺材料，不能据此断言原论文识别差。未知发表状态不等于未发表或质量低。

现有 lexicon/rating-rubric.json 的权重、阈值与封顶字段继续兼容。策略名、条目数量和样本标签只是检查线索，不能替代设计执行质量评估。旧词表中的“可直接引用”等是旧标签；展示使用当前 rating.scope/readinessLabel/usage/limitations，不沿用许可含义。

理论、描述性、因果研究的目标不同。检查解释须说明适用性，不能以方法名排序给所有论文统一的质量排名。仍有历史数值规则时，它们只是资料检查辅助视图；未覆盖的适用性和复算边界以实施报告为准。

## 检查轴与修正信息

- internal：识别相关资料、前提、威胁和检验是否充分，不是证明识别有效。
- external：样本、场景、机制与外推限制资料，不是证明结论可推广。
- sufficiency：所需字段与定位的覆盖程度；非空字段不等于事实正确。
- construct：度量说明的准备度；变量名不等于定义或度量有效性。
- publication：版本与发表记录核对信息；未知不能猜成正式同行评议。

权重变化后内容指纹变化是预期。可计算复现只说明规则对同输入得同结果，不证明原文判断正确。reproducible 应记录实际计分输入、证据状态与规则版本；缺项须报告。

## 定位与主张支持分开

| 信号 | 含义 | 不能推出 |
| --- | --- | --- |
| source | 抽取、现场定位或书目记录 | 来源天然可信 |
| match | 引文在正文文字匹配 | 主张语义成立 |
| pageCheck | 声明页码与计算页码核对 | 论文结论正确 |
| support / 支持状态 | 当前主张的支持判断边界 | 字段名相同就已支持 |
| verified | 兼容旧结构的定位信号 | 人工或因果判断已证实 |

无页表时页码未知；错页保留声明页与计算页，不制造第1页核验。父字段证据不能自动证明子主张。无正文命中可以保留抽取候选学习，但须显示待核查。

引文中的数字、前提与限制各有主张—证据映射，不能因数组非空就称整段被覆盖。可复制草稿不混入内部等级指令，仍需逐主张核对。

## 数值与关系线索

统一解析保留原文、状态和符号。Unicode负号须识别；零是零效应；空白、占位、n.s.不能变成正向数字。可解析不等于跨篇可比，还需核对单位、结果变换、估计对象、样本和模型。

卡片来源遵循 first_source/sources → refs_drop → refs 的优先顺序。人工剔除不能被自动强关联恢复；手工refs可覆盖自动剔除。作者/年份或主题匹配是候选，不能证明互引、直接检验理论或学界空白。

常识事实的独立来源与论文使用情境分开。关键词命中或论文data证据不能证明整段制度描述。无独立来源须标待核查。

## 学习与个人状态

题面 → 独立口述/作答 → 揭示参考表述与证据 → 按量规自评。自评不是客观掌握度，参考答案仍需核对。

- 默认间隔为 [1,3,7,16,35,75] 天，参数必须合法。
- 每项按自己首次纳入日期排程，不继承全库早年的到期日；新旧内容版本练习须区分。
- 评分是数字整数0–4，先取当前 itemVersion；一次作答一个 attemptId。
- 网络失败或坏回执不代表未写入，同编号原参数重试只计一次；更改评分/答案不能静默复用旧编号。
- 生成代与个人日志分开，重建保留日志；不要删整个学习根来刷新。

## 校验与发布

格式一致、位置可回溯、主张支持、规则复算和发布完整性分别检查。空库定位率为不适用，不显示100%可信。缺证据可保留为待核验材料；输入损坏、不可读和构建中断不得发布成“0条正常”的新代。

同一请求应固定完整一代，失败保留旧代。当前指针、清单和文件校验保证存储一致性，不保证论文质量。真实宿主、合成浏览器和引擎单元测试分别报告。
