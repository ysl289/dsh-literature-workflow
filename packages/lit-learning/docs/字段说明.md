# 字段说明

学习层 JSON 的兼容结构与字段含义。以下旧版示例中的具体数字不构成当前真实结果。

## 0.2 兼容与新增契约

- `rating.scope = library-readiness`，A–D 是本库资料准备度；优先展示 `readinessLabel/usage/limitations`。旧示例中的等级标签不是引用许可。
- 证据包含 `source/match/pageCheck/support/state/reason` 等独立信息。`verified` 是兼容定位信号，不代表主张支持已核验；未知页码为null。
- `review` 每项有 `id,kind,label,prompt,answer,evidence,itemVersion`。prompt是不含答案的题面；answer只在揭示后展示；版本由答案、证据和内容状态等稳定生成，不取构建时间。
- `review_record` 需 `{itemId,itemVersion,attemptId,grade,note?,source?}`，grade是数字整数0–4。同编号同参数取原回执；冲突参数、过期版本和未知条目应拒绝。
- `.generations/<generation>/` 存放生成代，`.current.json` 指向已提交代。查询认当前代；个人 `review/log.jsonl` 与生成代分离。
- 量级的 `parseStatus/direction` 描述单值；`comparisonStatus/comparisonReason` 表达比较边界，不能只看comparable就跨篇比数值。
- `readiness`、缺口覆盖候选和常识来源状态属于可选新字段，缺失时保守显示未知。

旧客户端须更新后再提交带版本的记录；保留旧日志，不猜测其内容版本归属。

## papers/&lt;paperId&gt;.json

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `schema` | number | 结构版本，当前 1 |
| `paperId` | string | 等于 `job.json.id`，全层唯一标识 |
| `citation` | object | `{apa, authors, year, journal, doi}`，来自抽取的 `apa_citation` 与 `meta` |
| `title` / `status` / `stage` | string | 论文标题、任务状态、当前阶段 |
| `strategy` | object | 归一后的识别策略：`{id, label, family, assumption, threat, portable, matched}`；`matched` 是原文里的写法 |
| `recital` | object | 四句复述，见下 |
| `rating` | object | 评级，见下 |
| `citations` | object | 安全引用表述，见下 |
| `questions` | array | 该篇的审稿/答辩问题 |
| `cards` | array | 关联卡片 `{id, title, shelf, strength, basis[]}` |
| `gaps` | array | 该篇引出的缺口 `{id, title, source}` |
| `evidence` | object | `{total, verified, fields[]}`：证据总数、正文可定位数、涉及字段 |
| `fingerprint` | string | 包含抽取、正文与分页等依赖；规则与卡片依赖另进入整层inputsHash |

### recital

```json
{
  "sentences": [
    { "key": "question", "label": "问题", "text": "...", "status": "ok",
      "evidence": [ { "field": "research_questions.0", "page": 1, "segment": 17,
                      "quote": "...", "verified": true, "basis": "quote" } ],
      "missing": [] }
  ],
  "complete": true,
  "missing": [],
  "oneLine": "..."
}
```

- `key` 固定为 `question` / `identification` / `magnitude` / `failure`，顺序固定。
- `status`：字段生成状态；ok不代表主张已证实。candidate/insufficient表示待核查或缺字段，不用摘要静默补成确定事实。
- `magnitude.direction`：`正向` / `负向` / `零效应` / `未标注`，由首个核心系数的符号推出。

### rating

```json
{
  "rubricVersion": 1,
  "axes": {
    "internal": { "score": 3.7, "reasons": [ { "text": "...", "points": 3.1,
                  "status": "ok", "evidence": [...], "note": "" } ],
                  "degraded": false, "inputs": { "strategy": "MOVER", "base": 3.1 } },
    "external": { ... }, "sufficiency": { ... }
  },
  "modifiers": {
    "construct": { "score": 2, "label": "...", "ratio": 1, "reasons": [...] },
    "publication": { "score": 1, "label": "已流通工作论文", "reasons": [...] }
  },
  "total": 10.21, "maxTotal": 12, "ratio": 0.851,
  "grade": "B", "gradeLabel": "可用需限定", "usage": "...",
  "capped": [ { "id": "workingPaperCap", "grade": "B", "reason": "...", "value": 1, "threshold": 1.5 } ],
  "rationale": "三轴合计 10.21/12（85%）……",
  "degraded": ["内部效度存在无证据判断"],
  "reproducible": { "inputs": { ... }, "rubricVersion": 1, "lexiconVersion": 1 }
}
```

- `reasons[].status`：`ok` 计分；`missing` 不计分，`note` 说明缺什么。
- `reproducible.inputs` 需与实际证据状态和规则版本审阅；规则可复算不等于原文判断正确。
- `capped` 为空数组表示没有触发封顶。

### citations

```json
{
  "authorYear": "Lerner（2024）",
  "grade": "B",
  "levels": [
    { "id": "L1", "label": "一句话", "text": "...", "evidence": [...] },
    { "id": "L2", "label": "一段话（含识别与量级）", "text": "...", "evidence": [...] },
    { "id": "L3", "label": "带限定条件（组会/审稿可用）", "text": "...", "evidence": [...] }
  ],
  "forbidden": [ { "pattern": "本文证明了 X 导致 Y", "reason": "...", "alternative": "..." } ]
}
```

`forbidden` 由评级与设计自动生成：非 RCT 不得写「证明」；C/D 档不得列为「一致证据」；非正式发表不得标「已发表文献」。

## indices/strategies.json

```json
{
  "version": 1, "papers": ["paper_..."],
  "strategies": [ { "id": "DID", "label": "双重差分", "family": "准实验",
                    "assumption": "...", "threat": "...", "portable": 3,
                    "papers": [ { "paperId": "...", "grade": "A", "variant": "staggered DiD",
                                  "assumptionUsed": "..." } ],
                    "count": 2, "crossNote": "..." } ],
  "matrix": { "paper_...": { "DID": true, "MOVER": false } },
  "gaps": []
}
```

`portable`（0–3）是我对「这个策略能搬到别的题目上有多容易」的粗评，不是论文的评价。

## indices/magnitudes.json

```json
{
  "version": 1, "total": 26,
  "themes": [ { "id": "SPILLOVER_SHARE", "label": "溢出/区位份额", "unit": "比例",
                "count": 6, "span": "2004–2024",
                "rows": [ { "paperId": "...", "term": "...", "coef": "0.16", "se": "...",
                            "stars": "", "direction": "正向", "comparable": true,
                            "evidence": [...] } ] } ]
}
```

`comparable` 表示 `coef` 能解析成数字，跨篇比数值时只比 `comparable: true` 的行。

## indices/links.json

```json
{
  "version": 1,
  "links": [ { "id": "paper_x::T-0010", "paperId": "...", "cardId": "T-0010",
               "cardTitle": "科学家流动", "shelf": "劳动与人力资本",
               "basis": [ { "role": "source", "kind": "citation", "detail": "作者姓氏 + 年份命中：lerner 2024" } ],
               "strength": "strong" } ],
  "byPaper": { "paper_x": ["T-0010"] },
  "byCard": { "T-0010": ["paper_x"] },
  "orphanCards": [], "uncoveredPapers": []
}
```

`strength`：`strong` = 引用文本命中（姓氏+年份或标题词重合）；`weak` = 只有概念命中。

## map/domain-map.json

| 字段 | 说明 |
| --- | --- |
| `nodes[]` | `{id, kind, label, meta}`；`kind ∈ paper / card / concept / theory / method` |
| `edges[]` | `{id, from, to, kind, label}`；`kind ∈ uses-concept / grounds-on / uses-method / card-strong / card-weak / card-relation / cites` |
| `eras[]` | 按年份分组的论文、概念、理论（演进视图） |
| `timeline` | `{min, max, count}` |
| `dialogues` | `{intra[], externalCount}`：本批论文之间的引用边 |
| `stats` | 各类节点与边的计数 |
| `dangling[]` | 端点缺失的边（校验项 `dangling` 的输入） |

## citations.json / exam/questions.json / gaps/pool.json / commonsense/library.json

- `citations.json`：`{version, note, papers: [{paperId, title, grade, ...citations}]}`
- `exam/questions.json`：`{version, total, questions: [{id, paperId, kind, question, targets[], answerHint, evidence[]}]}`；`kind ∈ 审稿人 / 答辩 / 组会`；跨篇问题的 `paperId` 为空、`targets` 列出涉及的论文
- `gaps/pool.json`：`{version, total, gaps: [{id, title, source, whyOpen, data, strategy, difficulty, cards[], evidence[], from}]}`；`source ∈ 作者自述（future_research）/ 局限外推（limitations）/ 卡片未被论文覆盖 / 评级驱动`
- `commonsense/library.json`：`{version, total, entries: [{id, kind, label, fact, whyItMatters, caveat, usedByPapers[], usedByCards[], evidence[]}]}`；`kind ∈ dataset / institution`

## report/validate.json

```json
{
  "version": 1,
  "summary": { "ok": true, "checks": 10, "errors": 0, "warnings": 0,
               "contentHash": "...", "evidenceLocateRatio": 0.75 },
  "checks": [ { "id": "evidence", "label": "证据可回溯", "level": "error",
                "ok": true, "detail": "...", "violations": [], "violationCount": 0 } ]
}
```

`level`：`error` 影响 `summary.ok`；`warn` 只提示。十个校验项：

| id | 检查什么 | 级别 |
| --- | --- | --- |
| `evidence` | 每条计分理由与复述句都挂得上证据 | error |
| `evidence-located` | 带页码/段号的证据占比 ≥70% | warn |
| `dangling` | 关联、地图边、卡片关系目标都有实体 | error |
| `reasons` | 每个轴与等级都有成文理由 | error |
| `verbatim` | 没有 ≥300 字连续原文搬运 | error |
| `boundary` | 配置没有放开写卡片库/写学习层外 | error |
| `coverage` | 四句复述齐全 | warn |
| `idempotent` | 内容指纹与上次一致 | warn |
| `abstract` | 没有整段复制摘要 | error |
| `anchors` | 问题与缺口都锚定到存在的论文 | error |

## manifest.json

| 字段 | 说明 |
| --- | --- |
| `schema` / `plugin` | 结构版本与包名 |
| `generatedAt` / `createdOn` | 本次生成时间 / 首次构建日期 |
| `inputs` | 与 dashboard.inputs 相同 |
| `contentHash` | 内容指纹（只覆盖内容文件） |
| `incremental` | `{fingerprints, reused[], written[], unchanged[]}` |
| `outputs` | `{content[], state[]}`：两类文件清单 |
| `rebuild` | `{command, preserved[], note}` |
| `readonly` | 只读声明 |
| `config` | 生效配置（不含凭据） |
| `durationMs` | 构建耗时 |
