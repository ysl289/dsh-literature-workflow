# 查重协议

目标：**既不重复造卡，也不错并两张本该分开的卡。** 后者比前者更贵——合并容易，拆分要重建链接和来源。

## 一、两步流程

```
脚本初筛（确定性）  →  模型复核（语义判断）  →  定级  →  执行
kcard.py check          读候选卡的 definition/mechanism
```

只做第一步会漏判同义表述；只做第二步会因记忆漂移而误判。两步都要。

## 二、归一化规则（脚本内置）

对标题、别名、英文名逐个归一化后比对：

1. 全角转半角，去除所有标点、空白、引号
2. 转小写
3. 剥离后缀词：`理论 / 假说 / 假设 / 效应 / 定律 / 模型 / 定理 / 悖论 / 原理 / 框架`，以及英文 `theory / hypothesis / effect / law / model / theorem / paradox / principle / framework`
4. 剥离前缀词：`the / a / an`

例：`Absorptive Capacity Theory` → `absorptivecapacity`；`企业吸收能力理论` → `企业吸收能力`。

## 三、相似度算法

对每张候选卡，取以下分数的最大值作为 `score`：

| 信号 | 分数 | 说明 |
| --- | --- | --- |
| 归一化串完全相等 | 1.00 | 强命中 |
| 任一等价别名命中 | 0.97 | 强命中 |
| 中文字符 bigram Jaccard | 0–0.95 | 抓词序变化 |
| 序列相似度（difflib） | 0–0.95 | 抓错字、增减字 |
| 英文串完全相等 | 0.95 | 强命中 |

## 四、阈值与四态

| score | 脚本建议 | 模型动作 |
| --- | --- | --- |
| ≥ 0.92 | `duplicate` | 复核：确认是同一理念 → 跳过并追加来源；确认是不同理念 → 降为 `related` |
| 0.72 – 0.92 | `suspect` | **必读候选卡正文**，判 `variant` / `related` / `new` |
| < 0.72 | `new` | 快速扫一眼候选标题，无明显重叠即可写卡 |

脚本输出 `suspect` 时**不许直接写卡**，必须打开候选卡读 `核心命题` 与 `关联与争议` 两节。

## 五、四态的执行细则

### duplicate（跳过）
- 不动原卡标题
- 在 `sources` 追加：`citation` / `locator` / `role`
- `updated` 改为今天
- 若本次文献提供了新的证据或反例，在正文相应小节补一句，并标注来源

### variant（并入）
- 新名字进 `aliases`
- 正文新增 `### 版本差异` 小节，写清：谁在何时怎么表述、差别在哪、为什么仍算同一理念
- 不改 `id`、不改文件名

### related（建新卡 + 互链）
- 新卡 `relations` 加一条指向旧卡
- **旧卡也要加一条反向边**，单向链接等于没链
- 边类型要选准：上位 / 下位 / 对立 / 互补 / 前置 / 应用于

### new（写卡）
- 模型把整张卡一次写完（frontmatter 含 `shelf`，正文不留「待补」）
- `kcard.py ingest <文件> --shelf <书架>` 收录；有重复或质量不达标会被拒绝（退出码 3）
- 收录后至少挂一条 `relations`，避免孤岛，再跑一次 `reindex`

## 六、边界案例（容易判错的）

| 情形 | 判定 | 理由 |
| --- | --- | --- |
| 逆向选择 vs 道德风险 | `related`（互补） | 同属信息不对称，机制方向不同：一个在交易前，一个在交易后 |
| 规模经济 vs 范围经济 | `related` | 一个来自产量，一个来自品类 |
| 挤出效应 vs 替代效应 | `related`（对立/互补视语境） | 前者是政府支出的宏观语境，后者是相对价格 |
| 知识的非竞争性 vs 知识的溢出 | `related`（前置） | 非竞争性是溢出得以发生的前提之一 |
| 吸收能力 vs 动态能力 | `related`（上位：动态能力包含） | 不是同一层级 |
| 搜寻匹配 vs 匹配函数 | `variant` | 后者是前者的形式化表述，同一理念 |
| 交易成本 vs 交易费用 | `duplicate` | 纯译名差异 |
| 卢卡斯批判 vs 理性预期 | `related`（前置） | 前者是后者的政策含义 |

## 七、复核时的自问四句

1. 两张卡说的"因为"是同一个因果机制吗？
2. 把其中一张的边界条件套到另一张上，会得出矛盾结论吗？会 → 不同理念。
3. 学界会把它们当同一个词条讨论吗？
4. 如果合并，以后要引用其中一个的批评，会不会被另一张污染？

第 2、4 题任一为"是"，就判 `related`，别合并。

## 八、失败信号

出现下列情况，说明查重环节出了问题，回头补：

- 库里出现标题高度相似的两张卡（`doctor` 会报 `near-duplicate`）
- 某张卡 `sources` 长期只有一条，而相关文献已读过多篇（该合并没合并，或该追加没追加）
- `INDEX.md` 里同一理念在不同 tag 下重复出现且 id 不同
